# nguyendinhthien Chat

React Native client for CSW434 Lab 1. See [../README.md](../README.md) for setup, tests, requirement review, and the two-client acceptance checklist.

- `App.tsx`: Home / Group navigation.
- `src/HomeScreen.js`: name validation and persistent local storage.
- `src/ChatScreen.js`: socket lifecycle, message list, timestamps and composer.
- `src/config.js`: development server URL.
- `__tests__/`: rendering and behavior tests.

Avatar initials are drawn from each participant?s display name. No third-party portrait URLs or sample author identity are embedded in the app.
